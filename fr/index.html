AVANT DE COMMENCER

Ce qu’il vous faut
pour vous connecter

Connectez-vous au Redmine que votre équipe utilise déjà. Si vous ne savez pas si son API REST est activée, contactez votre administrateur Redmine.

  • Redmine 6.0 / 6.1 / 7.0Versions compatibles.
  • HTTPS et API RESTVotre Redmine doit être accessible depuis votre iPhone en HTTPS et son API REST doit être activée.
  • L’URL de Redmine et votre clé d’APIUtilisez l’adresse que vous ouvrez habituellement dans votre navigateur. Pour obtenir votre clé d’API, ouvrez Redmine depuis l’écran de connexion de l’application.

Selon les paramètres de votre Redmine, la connexion ou certaines opérations peuvent ne pas être disponibles.

自分が担当するRedmineのタスクを、iPhoneから短い操作で報告するアプリです。本アプリはRedmineの公式アプリではなく、Redmineの開発者とは関係ありません。

App Storeからダウンロード

  • 自分や所属グループが担当する未完了のタスクを一覧で確認できます。グループが担当するタスクにはグループ名が表示され、期限を過ぎたタスクは赤で表示されます。
  • タスクの行を右にスワイプすると、完了にできます。取り消しの条件は「よくある質問」をご覧ください。
  • タスクの行をタップすると、説明や添付ファイルを確認できます。画像はアプリ内で開いて拡大できます。説明や添付ファイルがあるタスクには、一覧にアイコンが表示されます。
  • タスクの行をタップすると、過去のコメントを新しい順に確認できます。自分のコメントには「自分」と表示されます。前回開いたあとに更新されたタスクには、一覧に点が表示されます。
  • 「コメントを書く」をタップすると、過去のコメントを読みながらコメントを作成・送信できます。送信したコメントはRedmineの履歴に残ります。
  • 一覧に複数のプロジェクトのタスクがある場合は、タイトル横の「絞り込み」アイコンから、表示するプロジェクトを選べます。選択内容は、次回アプリを開いたときも引き継がれます。

接続に必要なもの

  • Redmine 6.0・6.1・7.0のいずれか。
  • お使いの端末から、接続先のRedmineにHTTPSでアクセスできること。
  • 接続先のRedmineでREST APIが有効になっていること。不明な場合は、Redmineの管理者に確認してください。
  • ご自身のRedmineのAPIキー。アプリの接続画面にある「APIキーをRedmineで取得」から取得できます。

接続先によっては利用できない場合があります。詳しくは「動作未確認の環境」をご覧ください。

使い始める

  1. アプリを開き、接続先のRedmineのURLを入力します。
  2. 「APIキーをRedmineで取得」をタップします。ブラウザでRedmineが開いたらログインし、表示されたAPIキーをコピーします。
  3. BeatMineに戻り、「貼り付けて接続」をタップします。APIキーを取得済みの場合は、入力欄に貼り付けて「接続」をタップすることもできます。
  4. 接続すると、担当するタスクの一覧が表示されます。

困ったとき

画面に表示されたメッセージに合わせて、以下の対処方法をご確認ください。

接続できないとき

「Redmineに接続できません。」と表示された場合は、原因を示すメッセージを確認してください。URLやAPIキーに誤りがある場合は、それぞれの入力欄の下に表示されます。それ以外の原因は「詳細」から確認できます。

メッセージ対処方法
「RedmineのURLが正しくありません。」端末のブラウザで同じURLを開いてください。開けない場合は、URLの入力間違いや、社内専用のRedmineに社外から接続している可能性があります。
「APIキーが正しくありません。」「APIキーをRedmineで取得」からAPIキーをコピーし、貼り付け直してください。Redmineにアクセスする前に別の認証（Basic認証など）が必要な環境は、動作を確認していません。
「RedmineのAPIが無効です。」Redmineの管理者に、REST APIを有効にするよう依頼してください。
「Redmineの証明書を確認できません。」端末で接続先の証明書を確認できない状態です。Wi-Fiへのログインが完了しているか、端末の日時が正しいかを確認してください。自己署名証明書や社内CAが発行した証明書を使う環境は、動作を確認していません。

タスクの読み込み・完了・コメント送信ができないとき

メッセージ対処方法
「ネットワークエラー」通信できる場所で、もう一度お試しください。Redmineが一時的に応答しない場合にも表示されます。
「他のユーザーによって更新されています。再読み込みしてください。」ほかの利用者がタスクを更新しています。一覧を再読み込みし、最新の状態を確認してから操作してください。
「完了する権限がありません。」（コメント・読み込みも同様）操作に必要な権限がありません。Redmineの管理者に相談してください。
「未完了の子タスクがあります。」先にすべての子タスクを完了してください。
「ブロック元のタスクが未完了です。」Redmineの「関連するチケット」を確認し、ブロック元のタスクを先に完了してください。
「変更できませんでした。」Redmineが変更を受け付けませんでした。完了時に入力が必要な項目がある場合などに表示されます。その場合は、RedmineのWeb画面で必要な項目を入力して完了してください。
「送信完了を確認できませんでした。再読み込みしてください。」送信内容がRedmineに反映されたか確認できない状態です。一覧を再読み込みしてください。
  • Redmineを読み込めても反映を確認できない場合は、その送信の確認を終了し、次の完了やコメントの送信ができるようになります。
  • 圏外などでRedmineを読み込めない間は、次の完了やコメントの送信はできません。ただし、再読み込みしても2回続けて確認できない場合は、その送信の確認を終了します。アプリを開き直しても、この回数は引き継がれます。
  • 確認を終了したコメントは下書きに残ります。すでに届いている可能性があるため、再送する前にRedmineの履歴を確認してください。
「アプリのエラーです。再読み込みしてください。」一覧を再読み込みしてください。改善しない場合は、Redmineのバージョンが対応範囲内（6.0・6.1・7.0）か確認してください。

説明・添付ファイル・過去のコメントを確認できないとき

メッセージ対処方法
「アプリでは開けません」アプリ内で開けるのは、20 MB以下の画像（JPEG・PNG・GIF・WebP・HEIC）です。PDFなど、それ以外のファイルはRedmineのWeb画面で開いてください。
「リンクを開けませんでした。」タスクの説明にあるリンクをブラウザで開けませんでした。説明文は長押しで選択・コピーできます。URLをコピーし、ブラウザに貼り付けて開いてください。

画像を開く際に「ネットワークエラー」などが表示された場合は、上の「タスクの読み込み・完了・コメント送信ができないとき」をご確認ください。「再試行」をタップすると、画像を再読み込みできます。

過去のコメントを読み込めない場合は、「コメント 読み込めません」と表示されます。コメント欄のメッセージを確認し、「再試行」をタップしてください。原因と対処方法は、上の「タスクの読み込み・完了・コメント送信ができないとき」と共通です。過去のコメントを読み込めなくても、タスクの完了やコメントの送信は操作できます。

よくある質問

完了したタスクが「却下」など、意図しない状態になる
変更可能な終了扱いの状態が複数ある場合は、Redmineに設定された並び順で最初の状態を選びます。変更後の状態は、完了時の通知に表示されます。元に戻すには、タスクの行にある「戻す」、または通知の「取り消す」をタップしてください。ただし、一覧の再読み込み後やアプリの再起動後、元の状態への変更がRedmineで許可されていない場合は取り消せません。その場合は、RedmineのWeb画面で対応してください。Redmineの管理者が状態の並び順を変更すると、アプリで選ばれる状態も変わります。例えば「完了」を「却下」より上に配置します。
APIキーの取得時にパスワードを求められる（Redmine 7.0）
ログインから時間が経過すると、Redmineがパスワードの再入力を求めます。入力すると、APIキーが表示されます。
一覧に表示されるタスクが少ない
件数の横に「（2プロジェクト選択中）」などと表示されている場合は、プロジェクトで絞り込まれています。タイトル横の「絞り込み」アイコンから解除できます。このアイコンは、一覧に複数のプロジェクトのタスクがある場合に表示されます。
一覧に表示されないタスクがある
表示されるのは、自分または所属グループが担当する未完了のタスクです。開始日が未来のタスクと、終了したプロジェクトのタスクは表示されません。期限による絞り込みは行いません。
グループのタスクは誰が担当するのか
アプリが担当者を決めることはありません。グループ内で相談するか、Redmineで個人を担当者に指定してください。グループのタスクを完了すると、同じグループに所属するほかの利用者の一覧からも表示されなくなります。
説明に「h2.」「*」などの記号が表示される
アプリはタスクの説明をMarkdownとして表示し、見出し・箇条書き・太字・リンク・コードに対応しています。Textile形式の説明や、表・埋め込み画像は、書式の記号がそのまま表示される場合があります。
端末を手放す前に情報を削除したい
設定の「接続を削除」をタップしてください。APIキー、コメントの下書き、送信結果の確認用記録、プロジェクトの絞り込み設定、開いたタスクの記録が端末から削除されます。

動作未確認の環境

以下の環境では、動作を確認していません。

  • Redmine 6.0より前のバージョン
  • プラグインを導入したRedmine
  • クラウド版Redmine（My Redmine・Planioなど）
  • 自己署名証明書や社内CAが発行した証明書を使う環境
  • Redmineにアクセスする前に別の認証（Basic認証など）が必要な環境
  • SSOを利用する環境

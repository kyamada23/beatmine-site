條件

連線至團隊原本使用的 Redmine。如果不確定是否已啟用 REST API，請向 Redmine 管理員確認。

  • Redmine 6.0 / 6.1 / 7.0支援的版本。
  • HTTPS 與 REST APIiPhone 必須能透過 HTTPS 存取 Redmine，且 Redmine 必須啟用 REST API。
  • Redmine 網址與個人 API 金鑰請使用平常在瀏覽器中開啟的網址。您可以從 App 的連線畫面開啟 Redmine，取得 API 金鑰。

依 Redmine 的設定而定，可能無法連線或使用部分功能。

連線條件與限制 →
開始使用

連線後，開啟第一個任務。

  1. 輸入 Redmine 網址開啟 App，輸入平常使用的 Redmine 網址。
  2. 使用 API 金鑰連線透過「在 Redmine 取得 API 金鑰」複製金鑰，再回到 App 進行連線。
  3. 開啟負責的任務先確認任務內容。工作完成後，即可標記完成或留言回報。
